# 产品定义

## 1. 产品愿景

让不懂设计和 PowerPoint 自动化的用户，只用大白话描述主题、受众、用途、页数和风格，就能得到一份视觉结构清晰、对象可编辑、可直接演示的 PPTX。

## 2. 目标用户

- 需要快速完成开题、答辩或课程汇报的学生和教师。
- 需要制作周报、方案、复盘和内部汇报的职场用户。
- 希望先快速得到结构完整初稿，再在 PowerPoint 中继续编辑的个人用户。

## 3. 核心价值

- 纯文字输入：不要求用户准备模板、图片或源文件。
- 先看大纲：用户确认内容结构后才生成文件。
- 视觉结构化：DeepSeek 决定页面故事线、内容层级和语义化视觉结构。
- 原生可编辑：程序用 `python-pptx` 绘制文字、卡片、色块、节点和连接线，不生成整页图片。
- 真实预览：PNG 由 Microsoft PowerPoint 打开最终 PPTX 后导出，预览与下载文件一致。

## 4. MVP 用户流程

1. 用户输入 PPT 主题、受众、用途、页数和补充要求。
2. DeepSeek 通过 OpenAI 兼容接口生成结构化 `DeckSpec`。
3. 系统使用 Pydantic 校验模型结果。
4. 页面展示逐页大纲；用户确认、重新规划或放弃。
5. 用户确认后，程序用 `python-pptx` 绘制 PowerPoint 原生对象。
6. Microsoft PowerPoint COM 将最终 PPTX 逐页导出为 PNG。
7. 页面显示全部真实预览，并提供 PPTX 下载。

## 5. MVP 功能范围

### 5.1 必须实现

- Windows 本地部署，使用 Python 3.12、uv 和 Streamlit。
- 只凭自然语言生成合法 `DeckSpec`。
- `DeckSpec` 包含稳定唯一的 slide ID、内容结构、主题和受控视觉结构。
- 生成 PPTX 前展示并确认大纲。
- 支持 16:9 中文演示文稿和 Windows 常见中文字体。
- 使用 PowerPoint 原生文字框、形状、色块、卡片、节点和连接线组织页面。
- 输出对象可在 PowerPoint 中逐个选择和编辑。
- 使用 PowerPoint COM 导出 1920×1080 PNG 预览。
- 预览成功后提供 PPTX 下载。
- 规划、渲染或预览失败时显示明确错误，不伪造成功结果。

### 5.2 明确不包含

- Markdown、TXT、PDF、DOCX、PPTX、XLSX 素材解析。
- 文件上传、用户图片、图片搜索和 AI 文生图。
- MarkItDown。
- `SourceRef`、`AssetRef` 的后续使用或扩展。
- `PatchPlan`、多轮局部修改。
- 版本管理和版本回退。
- 自动 QA 系统和 PPTX 哈希/预览版本绑定。
- `image_text`、`full_image` 和 `chart` 布局。
- 自由拖拽画布、复杂动画、SmartArt、宏和嵌入式对象。
- 数据库、队列、多租户和多 Agent 框架。

现有代码中的兼容字段不代表 MVP 功能；除非重新评审产品范围，否则不得围绕这些字段继续开发。

## 6. 产品行为规则

- 缺少非关键参数时使用合理默认值；页数等关键要求必须遵守。
- 先设计整体故事线，每页只表达一个主要结论。
- 不编造用户未提供的具体数字、引用或事实。
- 模型输出语义化视觉结构，不输出任意文本框坐标。
- 应用根据受支持布局决定坐标、边距、字体和容量限制。
- 大纲确认前不生成 PPTX。
- 重新规划不得复用旧候选大纲。
- 失败结果不得覆盖或冒充上一次成功产物。
- 预览失败时不得使用程序单独绘制的图片替代。
- 不把整页位图包装成“可编辑 PPTX”。

## 7. 默认值

| 项目 | 默认值 |
|---|---|
| 画面比例 | 16:9 |
| 语言 | 简体中文 |
| 字体 | Microsoft YaHei，允许配置后备字体 |
| 页数 | 8 页；用户要求优先 |
| 主题 | 简洁蓝白 |
| 预览尺寸 | 1920×1080 |
| 输出格式 | PPTX；预览为 PNG |

## 8. MVP 成功标准

- 用户无需编辑 JSON 或编写代码即可从文字要求得到可下载 PPTX。
- 固定测试请求可生成 6～10 页、结构合法且视觉层次清晰的演示文稿。
- 每页包含受控数量的原生可编辑对象，不是整页截图。
- PowerPoint 可无修复提示地打开文件，中文字体、换行和布局正常。
- PNG 数量与 PPTX 页数一致，尺寸为 1920×1080，且全部来自最终 PPTX。
- 普通自动测试不访问网络、不启动 PowerPoint；真实集成测试可显式启用。
- 任何失败都不会提供不存在、损坏或只有部分页面的产物。
